💡 Cách hoạt động:
Encode — File gốc → chia chunk → Fountain Codes → nhúng vào video frames (FFV1/4K) → file MKV
Decode — MKV → extract frames → khôi phục data → file gốc y hệt (lossless)

⚡ Upload lên YouTube: Video MKV → convert sang MP4 → upload YouTube (unlisted) → tải về bằng yt-dlp → decode lại = file gốc!
